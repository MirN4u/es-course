МК2 для предмета встроенные системы

Проект тестировался на платформе STM32CubeIDE, для запуска на локальной машине требуется скачать дополнительные библиотеки
Проект представляет из себя таймер, управление осуществляется при помощи клавиш чисел для выбора сколько времени потребуется на отсчёт
а также клавишь # и * для начала отсчёта и отметы отсчёта
